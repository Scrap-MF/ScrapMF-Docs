# Archive de descarga

Doctor reporta la memoria de descarga por cuenta bajo `archive/`.

- **empty** — aún no hay registros (aparece tras el primer scrape).
- **N media across M account(s)** — cuenta las entradas JSONL en todos los
  directorios de site, más la ruta del archive.

El archive es texto plano que te pertenece: copia la carpeta `archive/` entre
máquinas y la memoria viene con ella. Desactívalo para una sola ejecución con
`--no-archive`.
