# Configuración

**Configuration** es la segunda entrada del menú principal. Edita cómo se
comporta scrapmf: sesiones de cookies, opciones por site, perfiles y valores
por defecto globales.

El menú tiene cuatro entradas:

- **[Perfiles de cookies](./cookie-profiles)** — conjuntos de cookies Netscape
  nombrados, capturados desde un navegador.
- **[Manage Sites](./manage-sites)** — TOML por red bajo `sites/`.
- **[Manage Profiles](./manage-profiles)** — personas y sus cuentas.
- **[General settings](./general-settings)** — directorio de salida, archive,
  cookies de navegador, plugins.

Todo se almacena bajo `~/.config/scrapmf/` (consciente de XDG). Consulta
[Resumen de configuración](../../configuration/overview) para el layout de
directorios y la precedencia de resolución.
