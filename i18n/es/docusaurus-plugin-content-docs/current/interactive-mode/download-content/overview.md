# 📥 Download content

**Download content** es la primera entrada del menú principal. Ejecuta scrapes
contra las cuentas o URLs que elijas y escribe los resultados bajo tu
directorio de salida.

Desde aquí puedes tomar una de tres vías:

- **[Perfil guardado](./saved-profile)** — reutiliza un perfil guardado y elige
  las cuentas y tipos de contenido que cubre.
- **[URL(s)](./urls)** — pega una o varias URLs; el site se auto-detecta por
  URL.
- **[Quick scrape](./quick-scrape)** — aplana el árbol de directorios a
  `<cuenta>/<contenido>`.
- **[Tasks](./tasks)** — batches de contenido guardados: contenido elegido una
  vez, reutilizado.

Todas las vías comparten el mismo dashboard, reporte de integridad y log
persistente al final de la ejecución. Consulta [flujos por site](./site-flows)
para el comportamiento que difiere por red (Twitter/X en dos pasadas,
Instagram posts/reels, …).
