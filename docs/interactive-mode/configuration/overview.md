# ⚙️ Configuration

**Configuration** is the second entry of the main menu. It edits how scrapmf
behaves: cookie sessions, per-site options, profiles and global defaults.

The menu has four entries:

- **[Cookie profiles](./cookie-profiles)** — named Netscape cookie sets captured
  from a browser.
- **[Manage Sites](./manage-sites)** — per-network TOML under `sites/`.
- **[Manage Profiles](./manage-profiles)** — people and their accounts.
- **[General settings](./general-settings)** — output dir, archive, browser
  cookies, plugins.

Everything is stored under `~/.config/scrapmf/` (XDG-aware). See
[Configuration overview](../../configuration/overview) for the directory layout
and resolution precedence.
