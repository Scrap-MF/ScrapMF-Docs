# ScrapMF — Safe, interactive archiver for social media galleries

**scrapmf** is a command-line orchestrator for [gallery-dl](https://github.com/mikf/gallery-dl).
It ships its **own pinned copy of the backend**, validates everything you type,
and wraps it in a friendly terminal UI so archiving a profile is as simple as
picking a username from a menu.

```bash
scrapmf
```
